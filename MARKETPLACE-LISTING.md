## C. PREMIUM (700–1000 palabras)

**Production-Ready White-Label Real Estate Marketplace — Cloudflare Edge Platform**

### The opportunity

Building a credible real-estate marketplace in 2026 means solving mobile UX,
secure authentication, media management, SEO, and increasingly AI-assisted
search — before you sign your first listing. That build costs a professional
team 550–1,500 engineering hours and 3–6 months of calendar time.

NEXO is that build, already done, deployed, and independently audited. It is
a complete white-label real-estate marketplace platform running on
Cloudflare's global edge network, offered as a software asset with full
source code, transfer documentation, and an engineering evidence trail of
21 audit gates.

### What the platform does today (verified in production)

**For buyers/visitors:** a mobile-first catalog with search, filters
(operation, type, province, bedrooms, price), property detail pages with
gallery and safe-purchase guidance, a fullscreen map with compact price
markers, side-by-side comparison of up to 5 properties, and WhatsApp
contact CTAs with brand-aware prefilled messages. Visitors can register,
log in, and sync favorites across devices. An AI assistant (Cloudflare
Workers AI) answers natural-language queries against the live inventory
and links real matching properties.

**For the operator:** a private admin panel with property CRUD,
drag-and-drop image upload to R2 object storage, gallery reordering,
click-to-geolocate mapping, and bulk CSV import/export. Listing identity
uses stable public codes (N-001) generated by an atomic sequence.

**For search engines and app stores:** server-injected meta/OG/JSON-LD per
property, dynamic sitemap/robots generated from the real origin, and a
dynamic PWA manifest — the platform is installable and works offline-tolerant
via its service worker.

### The white-label advantage

Rebrand without touching code. Brand name, tagline, description, primary
color, logo, WhatsApp number, contact details, social links, market
country, locale, currency, and map center are all environment variables.
The Worker injects them at the edge — header, footer, SEO titles, manifest,
WhatsApp messages, everything. One variable toggle (DEMO_MODE) switches the
labeled demo experience on or off.

### Engineering quality you can inspect

- **Security:** hash-based Content-Security-Policy (no unsafe-inline
  scripts), HSTS preload, scoped rate limiting (login brute-force and AI
  chat protected), PBKDF2-SHA256 password hashing, HttpOnly session cookies
  with SHA-256 server-side storage, deny-by-default authorization with
  audience-whitelisted serialization — owner PII is structurally
  unreachable from the public API.
- **Testing:** 249 automated tests across 15 suites, green on every push.
- **CI/CD:** GitHub Actions → quality gates → tests → automatic deploy.
  Instant rollback via Cloudflare versions.
- **Audit trail:** 21 documented gates (security, UX, white-label, buyer
  simulation, adversarial probes) with VERIFIED/INFERRED/UNKNOWN evidence
  classification — a due-diligence package most acquisitions never get.

### Architecture

One Cloudflare Worker (no microservices) + D1 (SQLite) + R2 (media) +
Vectorize (embeddings) + Workers AI + static assets. No servers, no
containers, no build step, no JS framework lock-in. Home page ~17 KB gzip.
Operational cost starts at $0 on Cloudflare's free tier and stays near-zero
until meaningful traffic.

### What you are buying

Full source code (MIT license), database schema and idempotent migrations,
demo-data tooling (reproducible, one-command removal), branding system,
CI/CD workflow, and complete documentation: buyer quickstart, takeover
guide, deployment runbook, security model, product spec, and the audit
report library. Optional: export of the current demo inventory and media.

### Honest disclosures — read before buying

- **Pre-revenue.** No revenue, no users, no customers, no traffic history.
  This is a software asset sale, not a business sale.
- **Demo inventory.** The 25 visible listings are clearly labeled DEMO
  content (banner + badges + image watermarks) so you can experience the
  product immediately. One property (N-001) is a real listing used during
  development.
- **Infrastructure transfer.** The domain and the seller's Cloudflare
  account are not included. You deploy to your own Cloudflare account with
  the included guide — verified path, ~45–90 minutes for a competent

- **Single-tenant.** One brand per deployment. Multi-tenant SaaS would be
  new development.
- **Market defaults.** Province lists and the legal purchase guide ship
  configured for Cuba. Adapting to another country requires small,
  precisely documented code edits (the brand, contact, currency and map
  itself are configuration).
- **Known limitations** are documented in the repository (password recovery

  pages hydrate client-side with server-injected meta).

A development agency or white-label builder adding a real-estate vertical;
